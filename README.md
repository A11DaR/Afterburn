# AFTERBURN · Янтарный пролив

Пиксельная авиааркада про F/A-18E Super Hornet. В «Перехвате» нужно сбить ведущего до рубежа выхода и разобраться с сопровождением. В «Догфайте» тебя ждут три дуэли один на один.

Для первого вылета нажми «Лётная школа». Кнопка «Управление и сигналы» открывает настройки и даёт прослушать предупреждения. Кнопка «Поделиться игрой» на сайте отправляет или копирует ссылку.

## Как играть

[Открыть игру в браузере](https://afterburn-hornet-pixel-sky.pearly-jam-3744.chatgpt.site). На первом вылете выбери **Аркада → Лётная школа**. Чтобы играть офлайн, собери автономный файл командой `python tools/build-offline.py PLAY.html` и открой его в браузере.

| Действие | Клавиша |
| --- | --- |
| Поднять или опустить нос | W / S |
| Повернуть влево или вправо | A / D |
| Разогнаться или затормозить | Shift / X |
| Отключить тягу | O |
| Потушить пожар после отключения тяги | P |
| Запустить выключенный двигатель | Дважды W за полсекунды |
| Пулемёт | E |
| Ракета после захвата цели на 1,5 секунды | R |
| Ловушки / бочка | F / Q |
| Кабина или вид от третьего лица | V |
| Смотреть назад | Удерживать C |
| Пауза | Esc |

В «Аркаде» можно вести самолёт мышью. Левая кнопка стреляет, правая выпускает ракету после захвата. На сенсорном экране веди пальцем по левой части и используй экранные кнопки.

## Пожар двигателя

При пожаре тяга падает, а огонь постепенно повреждает корпус. Нажми **O**, чтобы отключить тягу. Самолёт перейдёт в планирование. Нажми **P**, чтобы потушить огонь. Когда появится надпись «Двигатель выключен», быстро нажми и отпусти **W два раза**. Двигатель запустится примерно за секунду. Одиночное нажатие W по-прежнему поднимает нос.

В обеих камерах панель показывает следующий шаг. На телефоне касайся кнопки на панели, для перезапуска коснись её дважды.

## Высота и звук

Справа показано расстояние до поверхности в метрах. Над горой прибор отсчитывает высоту до склона, над проливом — до воды. При низком полёте шкала становится янтарной. При опасном сближении загорается красное табло.

Выбери **RU** или **EN** в панели «Сигналы». Выбор меняет голос, подписи на табло и подсказки тревоги. До старта и на паузе можно нажать любой из 18 сигналов и прослушать его. Команды «Крен влево» и «Крен вправо» учитывают рельеф впереди и положение игровой угрозы.

«Тяни вверх! Тяни вверх!» предупреждает о рельефе по курсу. «Критический угол атаки!» звучит при высоком угле атаки, «Высота опасная!» — при малом расстоянии до поверхности. Игра использует подходящий голос, установленный на устройстве, или встроенную запись на выбранном языке. Оба варианта работают офлайн.

Кнопка **Музыка** управляет только фоновой темой. Кнопка **Звук** отключает весь игровой звук. Во время речи музыка приглушается, после паузы продолжается с того же места. Язык и настройки звука сохраняются в браузере, если разрешено локальное хранилище.

Закрылки плавно выпускаются при торможении, на малой скорости и в крутом манёвре. Их движение видно снаружи, а в кабине HUD показывает угол выпуска. Ракетное попадание по цели создаёт огненный шар и разбрасывает обломки. При попадании по игроку взрыв виден со стороны удара, на фонаре остаются трещины, а индикатор корпуса показывает потерю прочности.

## Запуск после правки исходников

Из корня проекта запусти `python -m http.server 8000 --bind 127.0.0.1 --directory dist` и открой http://127.0.0.1:8000/ в браузере. На Windows с Python Launcher вместо `python` можно использовать `py`. Для статического хостинга размещай содержимое папки `dist` в корне сайта.

Пересобери автономную копию командой `python tools/build-offline.py PLAY.html`. Игровые проверки запускаются с Node.js 24.

```sh
node tools/check-flight.mjs
node tools/check-camera.mjs
node tools/check-arcade.mjs
node tools/check-radio.mjs
```
